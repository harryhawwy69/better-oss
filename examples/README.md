# Examples

Worked examples from real use. Nothing here is loaded by the plugin; these
files exist so you can see what finished inputs and outputs look like before
you write your own.

- [`walkthrough.md`](walkthrough.md): one real contribution (openmed issue
  #5295, pull request #5698) followed through every stage of the pipeline.
- [`openmed-5295/`](openmed-5295/): the drafts and tool outputs the walkthrough
  refers to: claim, repro report, plan, plan comment, test evidence, PR
  description, and the skills' graded outputs.
- [`search-strategy-full.md`](search-strategy-full.md): the author's full
  search strategy after many scans, as a worked example of how a strategy
  grows. The compact starting point is
  [`../defaults/search-strategy.md`](../defaults/search-strategy.md).

The prefilled starting points you copy and edit live in
[`../defaults/`](../defaults/), not here.
